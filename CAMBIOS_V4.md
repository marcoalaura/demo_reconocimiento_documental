# Cambios de la V4

- Presentación: regreso al diseño sobrio de la V2, 28 diapositivas sin memes ni láminas comparativas repetidas.
- Guía del expositor: 28 secciones sincronizadas con las diapositivas; teoría, guion, evidencia y anexos.
- Demo: **mismo motor funcional V3**, títulos públicos de interfaz actualizados a V4 y recursos de memes retirados.
- Muestras CE, IDPR y CA: recreaciones ficticias basadas en formatos, NO PDFs originales ni datos reales.
- No se prometen precisión validada, autenticidad de credenciales ni ahorro real a partir de la simulación de 50.000.

Ejecutar: `pip install -r requirements.txt` y `streamlit run app.py`. Para OCR se necesita instalar Tesseract en el sistema.
